A short vertical video for TikTok, ending with make.fun's referral end card.

## The video

`day-one-day-seven.mp4` (1080×1920, 9:16) — see `POSTING.md` for the posting steps and caption. The video is rendered in the agent session that built this entry, from real gameplay of the game at its two states, and ends with make.fun's 9:16 referral end card from the press pack (fetched from https://make.fun/press/manifest.json), carrying the entrant's referral code.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `VIDEO.json` (the TikTok address of the posted video) to `out/VIDEO.json`. Replace the placeholder in `VIDEO.json` with the real video address after posting, before submitting.
